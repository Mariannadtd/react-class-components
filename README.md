# Character Search — Next.js SSR

Rick and Morty character search migrated from Vite to Next.js App Router.

## Run locally

```bash
npm install
npm run dev
```

Production checks:

```bash
npm run typecheck
npm run lint
npm run build
npm start
```

## Architecture

- Next.js App Router with localized, file-based routes
- English and Russian UI powered by `next-intl`
- server-rendered search results driven by `q`, `page`, and `selected` URL parameters
- search form handled by a Server Action
- character details fetched and rendered in a Server Component
- statically generated About pages for both locales
- CSV generated by the `/api/csv` route handler
- images rendered with `next/image`
- localized navigation created with `next-intl/createNavigation`
- theme and selected-character state implemented with React Context

The application uses the public [Rick and Morty API](https://rickandmortyapi.com/).
