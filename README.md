# React Forms

React + TypeScript application with two form handling approaches:

- uncontrolled form;
- React Hook Form.

The app includes an accessible modal rendered with React Portal, Zod validation, Zustand state management, image upload to base64, password strength checks, country autocomplete, submission history, and test coverage.

## Scripts

```bash
npm install
npm run dev
npm run build
npm run lint
npm test
npm run coverage
```
